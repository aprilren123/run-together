# Design Flaws and Opportunities for Improvement

## 1. Confusing flexibility settings
- **Level:** Conceptual
- **Severity:** Moderate
- **Issue:** Participant 1 wasn't sure which flexibility fields were required when she only wanted to adjust the start time. Participant 2 understood the feature, so the confusion wasn't universal.
- **Improvement:** Let users enable flexibility for each field separately and only display the relevant inputs.
- **Severity reasoning:** The participant completed the task independently, but the confusion affected a core feature.

### 2. Unclear run creation form
- **Level:** Linguistic
- **Severity:** Moderate
- **Issue:** Participant 2 wasn't sure whether pace was required and felt the form asked for too much information. Both participants experienced some difficulty creating runs.
- **Improvement:** Clearly label optional fields and separate essential details from additional preferences.
- **Severity reasoning:** Both participants completed the task, but the difficulty appeared in both studies.

### 3. Hard to find date picker
- **Level:** Physical
- **Severity:** Minor
- **Issue:** Participant 2 overlooked the calendar button and initially thought she needed to enter the date manually.
- **Improvement:** Make the entire date field clickable and provide a clearer indication that it opens a calendar.
- **Severity reasoning:** The participant recovered without assistance after a brief hesitation.

### 4. Invitation feature discoverability
- **Level:** Conceptual
- **Severity:** Minor
- **Issue:** Participant 1 initially looked for invitations under Friends instead of the run details. She found the feature on her second attempt and later described it as intuitive.
- **Improvement:** Make the invitation action more prominent on run details or add an entry point from Friends.
- **Severity reasoning:** The participant recovered independently, and Participant 2 had no difficulty.
