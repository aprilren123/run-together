# User Journey

Jamie wants to share a five-mile run she is planning along the Charles for 10:00 AM. She adds Taylor as a friend and creates the run, indicating that she is flexible between 9:30 and 11:00 AM. Taylor accepts Jamie's friend request and sees Jamie's run while looking through her friends' upcoming runs. Taylor wants to join but cannot make it until 10:30 AM, so she suggests changing the start time to 10:30 AM. Jamie sees Taylor's suggestion and accepts it. The run is updated to start at 10:30 AM, Taylor is added as a participant, and both of them can see the updated plan.
