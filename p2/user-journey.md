# User Journey

Morgan wants to share a five-mile run she is planning along the Charles for 10:00 AM. She creates the run, indicating that she is flexible between 9:30 and 11:00 AM.

Meanwhile, Jamie wants to find friends to run with, so she sends Morgan a friend request. Morgan accepts the request, and Jamie can now see Morgan's run while browsing her friends' upcoming runs.

Jamie wants to join but cannot make it until 10:30 AM, so she suggests changing the start time to 10:30 AM. Morgan sees Jamie's suggestion and accepts it. The run is updated to start at 10:30 AM, Jamie is automatically added as a participant, and both of them can see the updated plan.
