# Updated User Journey

Morgan enjoys running with friends but finds coordinating plans through group chats inconvenient. Morgan decides to plan a five mile run along the Charles River Esplanade for Saturday at 10:00 AM and would like some company. Instead of messaging friends individually, Morgan creates a run on RunTogether, specifying the time, location, distance, and pace, while indicating that the start time is flexible.

Jamie, who is already friends with Morgan, opens RunTogether and discovers the run in the Home feed. Jamie would like to join but prefers starting at 10:30 AM. Rather than messaging Morgan separately, Jamie suggests the new time directly through the app. Morgan receives a notification, reviews the suggestion, and accepts it. The run updates to 10:30 AM, and Jamie is automatically added as a participant. Both can now see the same updated plan.

On Friday evening, Morgan realizes they can no longer make the run and cancels it through My Runs. Jamie receives a cancellation notification and sees that the run is marked as cancelled, avoiding an unnecessary trip to the Esplanade.

RunTogether makes it easier for friends to discover opportunities to run together, coordinate changes, and stay informed when plans change, without relying on scattered messages.
