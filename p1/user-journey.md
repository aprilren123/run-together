# User Journey

Taylor likes running with her friends, but they usually plan their runs separately because coordinating schedules takes more effort than simply deciding when to run on their own. On Friday, Taylor is planning to run about five miles the next morning. Earlier that day, her friend Jamie had added her own five mile run along the Charles to RunTogether ("Create a run" sketch), setting a planned start time of 10:00 AM and indicating that she would be flexible between 9:30 and 11:00 AM. When Taylor opens the Home Feed ("Home feed" sketch), she sees Jamie's upcoming run. Normally, Taylor might not have known about Jamie's plan until after the run had happened.

Taylor would like to join, but she cannot make it until 10:30 AM. She opens Jamie's Run Details ("Run details: flexible" sketch) and sees that 10:30 AM falls within Jamie's flexible time range. Instead of messaging Jamie and going back and forth about whether another time would work, Taylor selects `Suggest a Change` and proposes starting at 10:30 AM ("Suggest a change" sketch). The rest of Jamie's plan already works for her, so she does not need to propose changes to the distance, pace, or location.

Jamie sees Taylor's pending suggestion when viewing the run ("Manage suggestions: owner view" sketch). Since 10:30 AM is within the range Jamie was already willing to run, Jamie accepts the suggestion, which updates the shared run to 10:30 AM and adds Taylor as a participant. The other runners who had already joined also see the updated time. If the new time no longer works for them, they can leave the run or suggest another time that does.

The next morning, Taylor and Jamie meet for their run. What would otherwise have been two independently planned runs became a shared run with only a small amount of coordination. Taylor did not have to ask several friends whether they were running, and Jamie did not have to organize a group event. Sharing an existing plan was enough for them to discover that their runs could work together.
