# UI Sketches

Created with Figma

# Home feed

![Home feed](images/Home%20feed.png)

Friends' future runs are shown chronologically so runners can discover plans before they happen. Flexible runs indicate that the owner is open to adjusting some details, while fixed runs can be joined as is.

# Run details: fixed

![Run details: fixed](images/Run%20details%20fixed.png)

A fixed run can be joined as is. Since the owner has not specified any flexibility, friends can see the plan and who is participating but cannot suggest changes to its details.

# Run details: flexible

![Run details: flexible](images/Run%20details%20flexible.png)

A flexible run shows both the owner's current plan and the ranges they are willing to adjust. A friend can join the current plan immediately or suggest a change if the run almost works for them.

# Create a run

![Create a run](images/Create%20a%20run.png)

A runner shares the run they already intend to do by entering their planned time, distance, pace, and location. They can optionally specify acceptable ranges around the time, distance, or pace to show where they are willing to adjust their plan.

# Suggest a change (overlay on run details)

![Suggest a change](images/Suggest%20a%20change%20overlay.png)

A friend can propose specific changes to the details that do not work for them while leaving the rest of the run unchanged. Sending a suggestion indicates that they want to join if the owner accepts the proposed change.

# Manage suggestions: owner view

![Manage suggestions](images/Manage%20suggestions%20owner%20view.png)

The run owner can review proposed changes and decide whether to accept or reject them. Accepting a suggestion updates the shared run and adds the suggester as a participant, while the owner keeps final control over their plan.

# Calendar view

![Calendar view](images/Calendar%20view.png)

Upcoming runs are organized by date to help users see how their own plans and their friends' runs fit into their week.
