# Application Pitch

## RunTogether

**Motivation:** RunTogether helps friends who would like to run together but often end up running separately because they don't know when their plans overlap or because coordinating a casual run takes more effort than running alone.

### Share Runs

Runners can share runs they already plan to do, including details such as time, distance, pace, and location. Their friends can see these upcoming runs before they happen, making it easier to notice when someone's plan fits their own instead of finding out after the run is already over.

### Join a Run

When a friend posts a run that works for them, runners can join the plan directly. This lets someone turn an individual run into a social one without having to individually invite friends or start a new group conversation.

### Flexible Planning

Not every run needs to be completely decided before it is shared. Runners can leave details such as time or distance flexible, and interested friends can add what works for them. RunTogether can show where everyone's preferences overlap, helping the group settle on a plan without one person having to compare everyone's availability through separate messages.
