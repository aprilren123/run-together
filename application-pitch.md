# Application Pitch

## RunTogether

**Motivation:** RunTogether helps friends who would like to run together but often end up running separately because they don't know when their plans overlap or because coordinating a casual run takes more effort than running alone.

With **Share Runs**, runners can share runs they already plan to do, including details such as time, distance, pace, and location. Their friends can see these plans before they happen, helping them discover opportunities to run together that they might otherwise only find out about afterward. This lets runners make their plans visible to friends without having to reach out to everyone individually. If a friend's plan works for them, **Join a Run** lets them join directly, turning what started as an individual plan into a social run without requiring someone to organize a formal event or start a separate group conversation.

Not every run needs to be completely decided before it is shared. With **Flexible Planning**, a runner can leave details such as time or distance flexible, and friends who are interested can add what works for them. RunTogether can show where everyone's preferences overlap, helping friends settle on a plan that works without making one person responsible for comparing everyone's availability through back and forth messages.
